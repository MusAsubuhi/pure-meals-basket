PURE MEALS BASKET — IMAGES NEEDED
==================================
Drop each file into this /images folder using the EXACT filename listed
(case-sensitive, matches what index.html already references). Once a file
is added, its placeholder block on the site is automatically replaced —
no code changes needed.

Recommended formats: JPG for photos, PNG for logos (transparent background).
Compress everything before uploading (TinyPNG / Squoosh) — the site targets
under-3-second loads on 3G.

   What: PMB logo, square or near-square, transparent PNG background
   Size: ~200x200px (displayed at 48x48, but keep it crisp on retina screens)
